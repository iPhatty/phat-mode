# Silent decisions eval: 2026-11-06 baseline

Evaluated by hand on 2026-11-06, with throwaway scripts, before this kit and before #27 (silent decisions and
departures) existed. The method was the one this kit automates: a fresh Goldfish reviewer saw only the ticket, its
parent and the code at the commit the planner saw, and listed gaps; a judge scored each gap against the plan comment,
the PR and the merged code. These numbers are why #27 exists (see
[ADR 0005](../../../docs/adr/0005-silent-decisions-agreed-with-the-implementer-and-checked-by-the-spec-reviewer.md)).

Sample: 15 built tickets (phatty-lingo and phat-mode).

| Measure | Count |
|---|---|
| Tickets | 15 |
| Blocker/Major gaps | 124 |
| Real | 106 (85%) |
| Handled | 102 |
| Guessed | 3 |
| Missed | 0 |
| Moot | 1 |
| Decision visible in the plan comment | 95 |
| Decision visible in the PR only | 6 |
| Decision visible in the code only | 4 |
| Relevant ADRs that landed while the ticket waited | 12 |
| Relevant ADRs followed: yes / partly / no | 12 / 0 / 0 |

Across all 46 built tickets (not only the sample), 19 had an ADR added or changed between the ticket being written and
planning.

## Not measured

- **Recall** (real Blocker/Major gaps listed in the plan's silent decisions), **unreported departures**, and what the
  **Spec reviewer passed**: the runs predate #27, so they recorded no silent decisions or departures.
- How many ADRs in the windows were judged not relevant: only the relevant ones were counted.
- The guessed and missed gaps were not kept as a list.

This baseline is not re-scored with the kit's new fields; later results are compared with it on the table above.
